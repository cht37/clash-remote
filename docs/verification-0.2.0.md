# 0.2.0 验证记录

日期：2026-10-06。

## 本次改进

- 保存路由器后进入概览并显示保存成功反馈；新路由器的连接状态、名称与地址即时显示。保存失败保留输入与设置页，重复保存相同配置也触发刷新。
- 经典 Clash 猫咪图标，安卓自适应图标与 API 33+ 单色主题图标；保留 OpenClash MIT 素材声明。
- 四套持久配色，立即生效、深浅模式跟随系统；上传和下载曲线保留不同颜色与线型，并提供图例。
- GitHub 最新正式发行版检查、数字版本比较、发行说明与可信 APK 下载链接；下载由浏览器处理，安装由安卓系统确认。

## 实际验证

`scripts/build-local.ps1` 已实际执行：32 项核心测试、4 项 Compose / Robolectric 界面测试、APK 构建、Android lint 均通过。

保存回归测试先复现页面停留问题，再验证修复后的自动跳转、路由器信息及非法地址反馈。曲线颜色回归测试先复现同色问题，修复后验证四套配色在深浅模式中的颜色区分。更新检查另验证请求失败不会继续显示旧的“已是最新版本”。

Debug APK 版本名 0.2.0，versionCode 2；包名与首版一致，最低 API 26、target API 36。APK v2 签名校验通过。

完成一次独立代码审查；未发现阻塞性问题，指出的曲线区分问题已修复并通过回归验证。没有延期的代码审查发现。

## 限制

界面测试运行在 Robolectric，不代表已在真实手机或实际路由器上验收。设备桌面图标效果、浏览器下载、安卓安装及未来发行版的签名兼容仍需在真实设备验证。后续发布应保持签名密钥一致，并递增 versionCode。

实现时仓库尚无正式 Release，公开 latest API 返回 404；已验证此情况显示“暂无正式发行版”。发布正式版并附带 APK 后，检查界面将显示最新发行信息。
